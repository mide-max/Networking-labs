# CCNA Network Engineering Lab Portfolio

Hands-on network engineering labs built and documented while preparing for the CCNA 200-301, going beyond standard study labs into multi-device builds with full verification, failure testing, and design documentation.

**Background:** Computer Engineering graduate (OOU) with hands-on NOC/network engineering experience supporting live infrastructure for MTN Nigeria and Sterling Bank during NYSC. Currently building toward network security engineering / blue team work.

Each lab folder is self-contained: a README explaining the build and design decisions, exported configs, and verification screenshots.
